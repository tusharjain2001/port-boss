# Port Boss: rules for any Claude working here

- **Paid art pack + PUBLIC repo:** never stage/commit/push `Assets/ThirdParty/`, `Assets/Toon Harbor Pack/`, or any image made from the Toon Harbor pack. Before EVERY commit: `git diff --cached --name-only | grep -ciE 'ThirdParty|Toon Harbor'` must print `0`. Never `git add -f`.
- **No secrets** in the repo. **No spending** (free tools only) until Steam Early Access. **No AI-generated assets ship.** Ask Manan before spending, publishing or deleting.
- **One thing at a time**, on a branch, reviewed, then `main`. Manan or Tushar tests every ★ milestone (equal footing, Manan 3 Nov: either approval is final). Keep one `LOG.md` line per step.
- **Judge on looks and watch the capture video** before calling any build ready. Stylised (Ponyo Coast), never realistic.
- **Don't disturb the PC's user:** Unity in `-batchmode`, no pop-up windows without an OK, one Unity instance at a time.
- Scenes/prefabs are generated by code (`Assets/Game/Editor/M1Build.cs`, `Assets/Scripts/Editor/PortBossBuild.cs`): change the code, not the generated assets.
- Which doc wins on a conflict: `HANDOVER.md` §3 > `docs/plan/gdd/MANAN-CHANGES-1031.md` > `docs/plan/gdd/DISCUSS-inventory-and-fish.md` > `docs/plan/gdd/CHANGES.md` > the gdd sections > `docs/plan/replan/` > older docs.
