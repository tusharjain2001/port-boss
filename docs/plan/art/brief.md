# Port Boss concept art brief (for Grok image generation)

Game: 1-4 player online co-op physics game. Friends grow a small, run-down harbour into a big port across the bay from a rich rival. Comedy chaos while a ship is docked (wobbly stacks of crates, a rocking boat, a forklift that tips, things falling in the sea), cozy growth at night.

STYLE LOCK (every image):
- Stylised realism with a light painterly finish: like a polished indie game screenshot (think the look of a modern Unity URP game with soft painterly post-processing), NOT photoreal, NOT a toy/kids game, NOT chibi, NOT plastic low-poly.
- A slightly rusty working harbour, 1990s-to-today: weathered wood pier, wet concrete, corrugated sheds, rust streaks, ropes, bollards, tyres as fenders, gulls, a small tea stall with a hand-painted sign.
- Palette: grey-teal harbour water and sky, warm late-afternoon sun, saturated accents only on cargo: colour-coded crates and containers (blue, orange, green) with INVENTED brand names, hi-vis orange/yellow vests and hard hats on the workers.
- Characters: adult dock workers with slightly exaggerated, chunky proportions (readable from a distance), expressive poses, no big cute eyes, no children.
- Camera: third-person game camera, a bit above and behind, as a real gameplay screenshot. No HUD unless asked. No text except signs. No watermark, no logos of real companies.

Save each image as a PNG in this folder with the file name given in the prompt.
