# Port Boss: overnight build (29 Oct 2026)

Double-click **PortBoss.exe**. It opens windowed (1920x1080; drag the edge to resize). Have Steam running for co-op; solo works without it.

## What to do
You run a run-down fishing pier. Boats come in with a horn, dock, and the captain shouts a countdown: **two minutes**. Get the fish crates off the boat and onto the **buyer's table** (the striped awning on the quay, left of the pier). Each crate dropped on the table sells: **+$12**, or **$4 if it has spoiled** (green fish, flies).
When the countdown runs out the boat **leaves with whatever is still aboard**. Three boats a day, about 8 minutes. At night you get the day's card (money, crates sold, crates in the sea) and the **night shop**: the **hand trolley ($120)** holds 6 crates. Don't let go of it on the slipway.

## Controls
| | |
|---|---|
| WASD / mouse | move / look |
| Shift | sprint (the stack wobbles more) |
| Space | jump |
| E or right click | grab a crate; again to stack more (max 5) |
| Q | drop the top crate |
| Left click | throw the top crate |
| F | push / let go of the trolley |
| H | hide the controls panel |
| Esc | pause menu (quit, invite friends) |

Tips: a tall stack wobbles when you start, stop or turn sharply, and sprinting with 4–5 crates will topple it. There are holes in the pier. Crates float, and the tide carries them out.

## Co-op (2–4 players, Steam)
- Host: main menu, **Host co-op (Steam)**, then Esc and **Invite Steam friends** (or friends open **Join** and pick your port from the list).
- Join: **Join**, pick the port, **Join**. Uses Valve's free test app 480 (Spacewar), so Steam may show you as playing "Spacewar".
- LAN/same PC: Join, type the host IP, Connect (the host must be in co-op).

## Known issues
- Co-op was tested with two copies on one PC through a real Steam lobby (lobby join + game over LAN). Steam can't connect an account to itself, so the **Steam relay connection between two different accounts is untested**. If friends can't connect over Steam, try LAN/IP.
- Placeholder art: everything is grey-box primitives in a warm palette. Sounds are CC0 (see Assets/CREDITS.md); the ship horn is synthesised.
- Windows may ask for firewall access the first time you host co-op.
- Fell in the sea? You climb back out on the quay after a second.
